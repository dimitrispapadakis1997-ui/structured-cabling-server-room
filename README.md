# Structured Cabling & Server Room Installation

Photo documentation of a structured cabling project in a new-build server room: from raw cable runs to terminated, labelled and dressed racks.

> No company names, client data, IP addresses or floor plans are included. Photos only show the physical installation.

## Scope

- Cable pulling and routing for the data network (Cat6 copper)
- Patch panel installation and termination in 19" racks
- Rack-side cable management: horizontal cable managers, vertical bundles, cable ties
- Cable labelling for port identification
- Rack power distribution (PDUs) and UPS installation (Socomec Netys RT)

## What this shows

- Organised, serviceable rack layout: patch panels alternate with cable managers so patch cords stay tidy.
- Bundled and strapped rear cabling that leaves room for airflow and future changes.
- Labelled ports for fast troubleshooting.
- Power resilience: PDUs and UPS units mounted in the rack.
